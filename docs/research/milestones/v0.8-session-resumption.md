# v0.8: authenticated hybrid plus session resumption

**IMPLEMENTED / SOFTWARE VALIDATED — HARDWARE VALIDATION PENDING.**

v0.8 extends frozen v0.7: SMP remains disabled; full authentication uses
ML-KEM-768 + ephemeral application P-256, explicit human SAS comparison and
FINISHED_C/P. Protocol version and cryptographic domains are v0.8. A ticket is
committed only after successful authenticated full FINISHED completion.

The retained 32-byte K_RESUME permits a four-frame mutually authenticated resume
without ML-KEM, ECDH or SAS. Every resume has a fresh session ID, two fresh
nonces, new directional keys and confirmation keys. Ticket lifetime is 24 hours
without renewal and at most 100 successful resumes; the Peripheral stores one
ticket only in RAM. A DK reboot, missing/expired/exhausted ticket or failed resume
selects authenticated full fallback. Central tickets survive process restart.

The application data-plane correction retains the actual v0.7 crypto worker and
AES-GCM primitives: Secure Data writes, explicit random IVs, role/session/type/
sequence AAD, strictly increasing receive sequences and three six-byte
`PING n`/`PONG n` rounds, **43-byte frames**. Both full and resumed sessions use
this path. The initial unfinished CP4 reuse was removed from v0.8 because it
would introduce a second experimental variable. Frozen v0.7 was not redesigned.
