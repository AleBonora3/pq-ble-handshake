# Milestone v0.2 — ML-KEM-768 on-device

## Status

ML-KEM-768 has been successfully integrated and executed on the
Nordic nRF54L15 DK.

This milestone validates the cryptographic implementation locally on
the embedded device. It does not yet represent an end-to-end
ML-KEM handshake between the PC Central and the DK.

## Hardware and toolchain

- Board: Nordic nRF54L15 DK
- Target: nrf54l15dk/nrf54l15/cpuapp
- nRF Connect SDK: 3.0.0
- Zephyr: 4.0.99
- Zephyr SDK: 0.17.0
- Compiler: GCC 12.2.0
- Architecture: Arm Cortex-M33
- Optimization: -Os

## ML-KEM implementation

- Algorithm: ML-KEM-768
- Standard: FIPS 203
- Implementation: mlkem-native
- Version: v2.0.0
- Commit: d1b2fe782888bdb761a50336012923180be7f502
- Backend: portable C
- Randomized API: disabled for deterministic self-test
- Upstream cryptographic sources modified: NO

- Secret key: 2400 bytes

## BLE regression

After the ML-KEM self-test completes, the Bluetooth stack initializes
successfully and the device advertises as:

PQ-BLE-Device

The existing GATT transport implementation and demo public key remain
unchanged.

## Current architecture

At this milestone, ML-KEM KeyGen, Encapsulation and Decapsulation are
executed locally as an isolated startup self-test.

The ML-KEM implementation is not yet connected to the ciphertext
received over BLE.
